## 🛠 How to Publish on GitHub Pages

1. **Create a new GitHub repository** (e.g., `sunflower-yield-project`)
2. **Upload these three files** (`index.html`, `style.css`, `README.md`) to the root of the repo
3. Go to **Settings → Pages**
4. Under **Source**, select `Deploy from a branch`
5. Choose `main` branch, `/ (root)` folder, and click **Save**
6. Your site will be live at `https://your-username.github.io/your-repo-name` within a few minutes

## 🎨 Design Notes

- **Color palette:** Warm neutrals (`#faf8f4`) with sunflower gold (`#c9860e`) accent
- **Typography:** DM Serif Display (headings) + DM Sans (body) — loaded from Google Fonts
- **Layout:** CSS Grid, fully responsive down to 380px
- **Animations:** Intersection Observer–driven fade-in on scroll; pure CSS/JS, no libraries
- **Hero visual:** Fibonacci spiral rendered on `<canvas>` using the golden angle (φ ≈ 137.5°)
- **No frameworks, no build tools** — paste and publish directly
